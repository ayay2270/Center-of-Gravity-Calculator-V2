# Center of Gravity Calculator V2

桌面導向的 2D 重心 / 翻覆穩定性工程計算工具，用於快速評估機櫃與棧板系統向右側的靜態翻覆穩定性。

## Online Demo

[開啟線上計算機](https://ayay2270.github.io/Center-of-Gravity-Calculator-V2/)

## 主要功能

- 2D SVG 側視工程圖：尺寸、重心、重力線、支點與傾角即時更新。
- 棧板高度、棧板寬度、機櫃高度及目前傾角 θ 支援同步滑桿與數值輸入。
- 理論置中 / 手動重心模式；直接拖曳紅色 CG 點即可切換手動模式，雙向同步重心高度與左右偏移。
- CG 點可用方向鍵微調 1 mm，Shift + 方向鍵微調 10 mm。
- 世界座標鉛直重力線與固定的右下翻覆支點。
- 直立 0°、至 22°、臨界角快速操作。
- 臨界角、22° 設計裕量、目前穩定狀態及所需棧板寬度反算。
- 六步水平工程計算過程，可展開 / 收合，於目前工作階段保留收合狀態。

主要工作區以 1440 × 900 桌面視窗為目標，窄視窗可捲動操作。

## 工程計算

理論置中重心高度：

`Zcg = 機櫃高度 / 2 + 棧板高度`

右側翻覆時，重心至支點的水平距離：

`D = 棧板寬度 / 2 − Xcg`

臨界角：

`θc = tan⁻¹(D / Zcg)`

22° 目標所需距離：

`Drequired = Zcg × tan(22°)`

置中重心的精確所需棧板寬度：

`所需棧板寬度 = 2 × Zcg × tan(22°)`

手動偏移時，所需半寬 `W = Drequired + Xcg`，精確全寬為 `2W`。工程建議先將所需半寬向上取整至 10 mm，再乘以 2；預設精確全寬約 1112.7 mm，工程建議為 1120 mm。

- Zcg 由地面起算，手動重心高度不再加上棧板高度。
- Xcg 正值表示向右、靠近右側支點；負值表示向左、遠離右側支點。
- 本工具進行靜態翻覆篩選，並非動態翻倒模擬；不包含滑動、變形或衝擊分析。圖中機櫃寬度按棧板寬度示意。
- 理論置中假設未達目標時，需確認實際重心；此結果不代表實際產品必定翻覆。

## 22° 設計要求與目前狀態

兩項檢核分開判讀：

1. **設計要求**：θc ≥ 22° 為「符合 22° 規格」，否則為「未達 22° 規格」。
2. **目前狀態**：θ < θc 為「仍穩定」；相等時為「臨界狀態」；超過時為「超過臨界角」。臨界比較使用小量容差處理浮點誤差。

例如 θc = 21.6°、目前 θ = 16.0°，表示未達 22° 設計要求，但目前姿態仍穩定。

## 本機開發

建議使用 Node.js 24。

```bash
npm ci
npm run dev
```

開發網址：<http://127.0.0.1:4527/>。

測試、建置及預覽：

```bash
npm test
npm run build
npm run preview
```

`npm test` 包含 10 項工程測試，涵蓋理論預設值、手動正負偏移、低於 / 等於 / 超過臨界角、精確 22° 條件、寬度反算、支點座標轉換及無效尺寸。`npm run build` 包含 TypeScript 檢查。

`tests/browser-qa.mjs` 提供 `runBrowserQA(tab)`，可搭配 Browser 工具的 tab API 驗證滑桿、數值輸入、CG 拖曳、模式切換、傾角、重力線、固定支點及計算面板收合。

## 部署

更新 `main` 後，GitHub Actions 會自動執行依賴安裝、工程測試及建置，再部署至 GitHub Pages；也可手動觸發 workflow。

部署設定位於 `.github/workflows/deploy-pages.yml`，Pages 來源為 **GitHub Actions**。本機開發、建置與預覽使用 `/`，Actions 建置使用 `/Center-of-Gravity-Calculator-V2/`。
