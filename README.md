# Version A：2D 重心 / 翻覆穩定性計算機

獨立的新本機原型，以本次提供的 Version A 圖片為主要視覺與配置參考。沒有讀取或複用舊網站、舊重心計算機、其他概念專案或既有 Git repository 的原始碼；沒有使用 UI/UX Pro Max、frontend-design 或設計技能。

## 啟動

雙擊 `open-preview.cmd`。它先確認本專案預覽可用；若服務停止，會啟動隱藏的本機 Node.js 靜態伺服器、等待頁面就緒，再開啟預設瀏覽器。

網址：**http://127.0.0.1:4527/**。僅在執行本專案的電腦上有效。

開發：`npm install`、`npm run dev`。

建置：`npm run build`。啟動器會使用 `dist/` 中的完整建置檔案，不需保持開發終端機開啟。需要本機 Node.js。

## 計算與操作

Vite + React + TypeScript，SVG 工程圖。

預設：棧板高度 153 mm、寬度 1092 mm、機櫃高度 2448 mm、理論置中、目前傾角 16°。

理論重心：`Zcg = 機櫃高度 / 2 + 棧板高度`。

手動重心：Zcg 已由地面起算，不再加棧板高度。Xcg 正值向右、負值向左。

右側距離：`D = 棧板寬度 / 2 − Xcg`。臨界角：`atan(D / Zcg)`。

22° 所需半寬：`W = Zcg × tan(22°) + Xcg`。精確棧板寬度為 2W。工程建議先將半寬向上取整至 10 mm，再乘以 2。預設精確 1112.7 mm，建議 1120 mm。

設計要求與目前狀態分別比較；臨界值採用 1e−8 度容差以處理浮點誤差。「超過臨界角」是靜態條件判讀，並非動態翻倒模擬。

CG 可直接拖曳，會切換手動並展開重心設定。拖曳轉換為直立局部座標，因此傾斜時仍能正確同步 Zcg / Xcg。CG 點支援方向鍵 1 mm、Shift + 方向鍵 10 mm。

幾何尺寸與傾角支援同步滑桿、數值輸入。數值欄可保留精確小數，滑桿操作以 mm 或 0.1° 微調。無效或超範圍欄位會提示並於離開欄位時恢復／限縮，不渲染 NaN。

側視機櫃寬度按棧板寬度示意；參數上下限是本原型的控制範圍。圖面視角自動縮放，右側支點畫面位置保持固定；重力線始終鉛直。

計算過程預設收合，使 1440×900 的主要功能完整可見。展開後保留六個水平驗算卡片，允許頁面稍微向下延伸。收合狀態以 sessionStorage 保留於目前工作階段。

## 驗證

`npm test`：10 項工程測試，包括使用者指定的 8 種案例、固定支點轉換及無效尺寸。

`npm run build`：TypeScript 檢查及 Vite 建置。

`tests/browser-qa.mjs`：可由 Browser 工具的 tab API 執行 `runBrowserQA(tab)`，在 1440×900 驗證輸入、滑桿、拖曳、模式、傾角、重力線、支點、驗算收合及說明視窗。`qa/` 保留結果及畫面。

沒有部署、push、commit 或 Git 初始化。
